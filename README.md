# 🎮 Text Console RPG

> C++로 구현하는 텍스트 기반 콘솔 RPG 게임
> 내일배움캠프 C/C++ 팀 프로젝트

---

##  프로젝트 소개

콘솔 창에서 동작하는 턴제 RPG 게임입니다.
캐릭터를 생성하고, 몬스터와 전투하며 경험치와 골드를 획득해 성장시키는 게임입니다.
화려한 그래픽은 없지만, 실제 3D 게임의 핵심 로직(전투, 성장, 상점)과 동일한 구조를 C++로 직접 구현합니다.

## 📁 프로젝트 구조

```
NBC_Console_TeamProject/
├── TeamProject.sln              # Visual Studio 솔루션 파일
└── TeamProject/
    ├── TeamProject.cpp          # 메인 진입점
    ├── TeamProject.vcxproj      # 프로젝트 설정
    ├── TeamProject.vcxproj.filters
    ├── Player.h / Player.cpp    # 플레이어 캐릭터 클래스
    ├── Monster.h / Monster.cpp  # 몬스터 클래스
    ├── Item.h / Item.cpp        # 아이템 클래스
    ├── Battle.h / Battle.cpp    # 전투 시스템
    ├── Shop.h / Shop.cpp        # 상점 시스템 (도전)
    └── GameManager.h / GameManager.cpp  # 게임 전체 흐름 관리
```

> 구조는 개발 진행에 따라 변경될 수 있습니다.

##  핵심 기능

### ✅ 필수 기능

| 기능 | 설명 |
|------|------|
| 캐릭터 생성 | 이름 입력 후 초기 스탯(Lv.1, HP 200, ATK 30, EXP 0)으로 시작 |
| 몬스터 | 캐릭터 레벨에 비례한 랜덤 스탯으로 자동 생성 |
| 턴제 전투 | 플레이어·몬스터 자동 행동, 승리 시 EXP·골드·아이템 보상 |
| 레벨업 | EXP 100 달성 시 체력·공격력 상승 및 HP 회복 (최대 Lv.10) |
| 아이템 | 포션(HP +50) / 공격 버프(ATK +10, 해당 전투 한정) |
| 게임 로그 | 전투 이벤트 및 처치 몬스터 목록 콘솔 출력 |

### 🌟 도전 기능

| 기능 | 설명 |
|------|------|
| 보스전 | Lv.10 달성 시 보스 등장, 처치 시 게임 클리어 |
| 상점 시스템 | 골드로 아이템 구매·판매 (판매가 = 구입가 × 60%) |

## 🔄 게임 흐름

```
게임 시작
    ↓
캐릭터 이름 입력
    ↓
전투 (랜덤 몬스터)
    ↓
승리 → EXP / 골드 / 아이템 획득
    ↓
레벨업? → YES: 스탯 상승
    ↓
상점 방문? (도전 기능)
    ↓
Lv.10 도달? → YES: 보스전 (도전 기능)
    ↓
보스 처치 → 게임 클리어 🎉
패배 → 게임 오버 💀
```
